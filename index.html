Chatbot PyTorch

Récupérateur de clé WiFi

Comment retrouver un mot de passe WiFi oubié ?

Il faut trouver une manière de récupérer la clé WiFi enregistrée par la machine.

Créer un script qui ouvre automatiquement un terminal et éxécute les commandes nécessaires.
Moniteur GPU

Le gestionnaire de tâches par défaut de Linux ne surveille pas le GPU.

La solution est de créer son propre gestionnaire de tâches.

Automatiser l'éxécution de commandes "nvidia-smi" et afficher le résultat dans une interface Tkinter.
